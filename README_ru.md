# SCS Tools Manager

SCS Tools Manager — настольное приложение для установки, запуска, организации и создания инструментов для игр SCS Software, включая Euro Truck Simulator 2 и American Truck Simulator.

Оно объединяет готовые инструменты сообщества и Ваши собственные утилиты на HTML, Python, JavaScript или EXE в одном рабочем пространстве. Интерфейс доступен на русском и английском языках.

## Основные возможности

- Просмотр проверенных инструментов из онлайн-каталога.
- Скачивание, обновление, удаление и запуск ZIP-инструментов.
- Проверка архива по имени файла и контрольной сумме SHA-256.
- Обнаружение случайных дубликатов UID и запрет небезопасного запуска дубликатов.
- Запуск HTML-инструментов с Python- или JavaScript-действиями внутри менеджера на Windows и Linux.
- Запуск HTML-инструментов через приватный сервер `127.0.0.1` на macOS, когда встроенный WebEngine недоступен.
- Запуск совместимых EXE-инструментов на Windows.
- Установка инструмента для быстрого запуска через файл `.scstool`, ярлык в меню «Пуск» и/или ярлык на рабочем столе.
- Создание инструмента в трёх этапах: сведения, файлы проекта и визуальное редактирование HTML.
- Визуальное редактирование HTML, CSS-классов, глобальных стилей и стилей элементов.
- Связь HTML-элементов с действиями Python или JavaScript.
- Сохранение черновиков редактора, последней открытой вкладки и истории HTML-изменений.
- Запись действий приложения, предупреждений и ошибок в журнал.

## Разделы приложения

### Главная

На главной странице находится краткая информация о менеджере, статистика инструментов, ссылки на сообщества автора и инструкция по использованию интерфейса.

### Магазин

Магазин читает каталог проверенных инструментов с настроенного сайта. В карточке отображаются баннер, иконка, категория, описание, тип Runtime, версия, дата обновления и размер архива.

Менеджер сравнивает локальный архив с каталогом одновременно по имени и SHA-256:

- **Скачать** — архива нет на компьютере.
- **Обновить** — архив с таким именем есть, но его SHA-256 отличается.
- **Открыть** — проверенный архив уже скачан.

На странице инструмента доступны полное README, ссылки автора, скачивание и установка.

### Скачанные

Здесь отображаются все ZIP-архивы из локальной папки `tools`. На странице можно запустить, обновить, удалить или установить инструмент. Для установленного инструмента доступна деинсталляция: она удаляет `.scstool` и созданные ярлыки, но не скачанный ZIP-архив.

### Запущенные

Открытые инструменты располагаются во вкладках. HTML-инструменты могут обращаться к Python или JavaScript через мост инструмента. На Windows EXE-инструменты могут запускаться как нативные окна. После обновления можно перезагрузить уже открытую вкладку инструмента.

### Создание

Редактор инструмента состоит из трёх этапов:

1. **Информация об инструменте** — название, UID, описания, иконка, баннер, Runtime и необходимые для запуска файлы.
2. **Структура проекта** — добавление, изменение, импорт и организация файлов внутри ZIP-архива.
3. **Визуальный редактор** — HTML-код и визуальная разметка, стили, классы, глобальный CSS, действия и привязки элементов. Доступны отмена/повтор и кнопка тестирования.

UID — это 64-символьный идентификатор. Он должен быть уникальным: перед созданием архив проверяется на совпадение с уже существующими инструментами.

## Формат архива инструмента

Инструменты распространяются в ZIP-архивах. Базовый инструмент HTML + Python содержит:

```text
my_tool.zip
├── info.json
├── app.html
├── logic.py
├── icon.png
└── banner.png
```

В `info.json` хранятся метаданные и настройки Runtime. Упрощённый пример:

```json
{
  "uid": "64-character-unique-uid",
  "name": "Мой инструмент",
  "desc_en": "Для публикации обязательно описание на английском.",
  "desc_ru": "Описание на русском необязательно.",
  "version": "1.0.0",
  "icon": "icon.png",
  "banner": "banner.png",
  "runtime": {
    "type": "html_python",
    "entry": "app.html",
    "logic": "logic.py"
  }
}
```

Поддерживаются `html_python`, `html_js` и Windows EXE-инструменты. EXE-инструменты на системах, отличных от Windows, помечаются как недоступные.

## Действия HTML

HTML-элемент может вызвать действие в скрипте через `data-scs-action`:

```html
<button data-scs-action="create_list">Создать список</button>
```

Менеджер передаёт значения полей формы в назначенный Python- или JavaScript-файл. Ответ возвращается на страницу и может быть обработан функцией `window.renderTool(data)`.

## Установка и файлы `.scstool`

При установке всегда создаётся файл запуска `.scstool` с UID инструмента. Дополнительно можно выбрать ярлык на рабочем столе, ярлык в меню «Пуск» и единый файл `.scstool` со встроенным ZIP-архивом.

На Windows расширение `.scstool` связывается с SCS Tools Manager. Если файл запуска ссылается на ещё не скачанный инструмент, менеджер может загрузить проверенный архив из каталога. Неизвестный встроенный архив перед восстановлением явно помечается как непроверенный.

## Публикация в проверенном каталоге

Проверенный каталог задаётся файлом `site/verified_tools.json`. Каждая запись содержит как минимум UID, название, английское описание, категорию, баннер, иконку, Runtime, дату обновления, имя архива для скачивания, размер и SHA-256.

Для публикации подготовьте ZIP-архив инструмента и ZIP-архив либо ссылку с файлами публикации: `manifest.json`, баннером, иконкой и README на нужных языках. `README.md` содержит английское описание; `README_ru.md` и другие переводы необязательны.

## Сборка дистрибутивов

Запускайте сборочный скрипт на целевой операционной системе:

```powershell
python build.py
```

Скрипт при необходимости устанавливает отсутствующие Python-зависимости для сборки и создаёт нативные пакеты текущей платформы.

- **Windows:** портативный EXE, Setup EXE и MSI в `dist\Windows`.
- **Linux:** DEB и RPM в `dist\Linux`.
- **macOS:** DMG и PKG в `dist\MacOS`.

Для Windows-установщиков нужны Inno Setup и WiX. Для Linux необходимы системные утилиты сборки пакетов соответствующего дистрибутива. Для macOS нужны Xcode Command Line Tools.

Сборки нативные: Windows-пакеты собираются на Windows, Linux-пакеты — на Linux, а пакеты macOS — на macOS.

## Локальные данные и журнал

Установленное приложение хранит пользовательские данные в локальной папке данных ОС: настройки, скачанные инструменты, файлы запуска, кэш и журналы. Удаление самой программы не удаляет эти пользовательские данные автоматически.

Журнал приложения содержит действия пользователя, предупреждения и неожиданные ошибки. Его следует приложить при сообщении о проблеме.
